# Low-Latency Network Infrastructure

A reproducible Containerlab project for studying routed multicast delivery,
network failures, telemetry, and automated validation in low-latency trading
infrastructure.

## Status

Initial implementation is in progress. The first public milestone will provide
an FRR reference topology, repeatable validation, and documented test results.
Arista cEOS support will require a user-supplied image and will not redistribute
vendor software.

Source code, run instructions, CI, and evidence will be published as each
capability is implemented and verified.
